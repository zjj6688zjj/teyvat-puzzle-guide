# 米游社攻略爬取工具使用说明

本项目包含两个爬取脚本，分别用于单篇爬取和批量爬取米游社（miyoushe.com）攻略文章。

项目目录已按用途分组：

- `单个/` —— 单篇爬取相关文件
- `批量/` —— 批量爬取相关文件

运行脚本前，请先进入对应目录。

## 环境准备

### 1. 安装依赖

两个脚本都依赖以下 Python 包：

```bash
pip install requests beautifulsoup4
```

### 2. 确认 Python 版本

建议使用 Python 3.8 或更高版本。

---

## 单篇爬取：`单个/main.py`

适合只爬取单篇文章的场景。

### 使用步骤

1. 打开 `单个/main.py`。
2. 修改文件顶部的配置：

   ```python
   ARTICLE_URL = "https://www.miyoushe.com/ys/article/76382075"
   POST_ID = "76382075"
   GAME_ID = "2"   # 原神为 2，其他游戏见下方映射表
   ```

3. 运行脚本（无论从哪个目录运行，输出都会固定保存到 `单个/output/`）：

   ```bash
   python 单个/main.py
   ```

### 游戏 ID 映射表

| 游戏 | URL 板块 | GAME_ID |
|------|----------|---------|
| 崩坏3 | `bh3` | 1 |
| 原神 | `ys` | 2 |
| 未定事件簿 | `wd` | 3 |
| 大别野 | `dby` | 4 |
| 崩坏：星穹铁道 | `sr` | 6 |
| 绝区零 | `zzz` | 8 |

## 批量爬取：`批量/batch_crawl.py`

适合一次性爬取多篇攻略。

### 使用步骤

1. 准备 URL 列表文件，默认读取 `批量/urls.txt`。

   每行写入一个米游社文章链接，空行和以 `#` 开头的行会被忽略：

   ```text
   # 原神攻略
   https://www.miyoushe.com/ys/article/76382075
   https://www.miyoushe.com/ys/article/76857165

   # 星铁攻略
   https://www.miyoushe.com/sr/article/12345678
   ```

2. 运行批量脚本（无论从哪个目录运行，输出都会固定保存到 `批量/output/`）：

   ```bash
   python 批量/batch_crawl.py
   ```

   如果 URL 列表文件不是默认的 `批量/urls.txt`，可以使用 `--urls-file` 指定（相对路径以当前运行目录为准）：

   ```bash
   python 批量/batch_crawl.py --urls-file 批量/my_urls.txt
   ```

3. 如需强制重新下载已存在的文章，加上 `--force`：

   ```bash
   python 批量/batch_crawl.py --force
   ```

### 批量脚本特性

- 自动从 URL 中识别 `post_id` 和游戏板块，从而选择对应的 `game_id`。
- 每篇文章保存在独立的 `output/{post_id}/` 文件夹下，互不影响。
- 已存在的文章默认会自动跳过，避免重复下载。
- 单篇文章失败不会影响后续文章继续爬取。
- 下载过程中会自动休眠，降低被拦截的概率。

## 输出目录结构

无论是 `单个/main.py` 还是 `批量/batch_crawl.py`，每篇文章都会保存为如下结构：

```text
单个/output/ 或 批量/output/
└── {post_id}/                     # 文章 ID，每个攻略独立一个文件夹
    ├── text/
    │   ├── article.txt            # 纯文本阅读版
    │   └── article.json           # 完整元数据 + 原文 HTML + 纯文本
    ├── images/
    │   ├── img_001.png
    │   ├── img_002.jpg
    │   └── images.json            # 图片 URL 与本地文件对应清单
    └── videos/
        ├── video_001.mp4          # 米游社原生视频（如有）
        ├── embed_001.html         # Bilibili 等 iframe 嵌入视频页面（如有）
        └── videos.json            # 视频清单（含类型、URL、本地文件路径）
```

示例（单篇爬取）：

```text
单个/output/
└── 76382075/
    ├── text/
    │   ├── article.txt
    │   └── article.json
    ├── images/
    │   ├── img_001.png
    │   ├── img_002.png
    │   └── images.json
    └── videos/
        └── videos.json
```

## 常见问题

### 1. 请求被拦截或返回错误

- 检查网络连接。
- 确认 URL 可以正常在浏览器中打开。
- 如果频繁请求，可适当增大 `SLEEP_INTERVAL` 和 `ARTICLE_SLEEP_INTERVAL`。
- 必要时更换 `User-Agent` 或添加 Cookie。

### 2. 图片或视频下载失败

- 图片/视频链接可能已失效或被防盗链。
- 可检查对应 `images.json` 或 `videos.json` 中的失败记录。
- 文本内容即使媒体下载失败也会正常保存。
- 对于 Bilibili 等 iframe 嵌入式视频，脚本会保存嵌入页面为 `embed_xxx.html` 作为引用，无法直接下载为 MP4。

### 3. 如何更换游戏

- `单个/main.py`：修改顶部的 `GAME_ID`。
- `批量/batch_crawl.py`：使用对应游戏的米游社文章链接即可，程序会自动识别。

### 4. 批量脚本能否从 Excel 或 CSV 读取链接

当前版本只支持每行一个 URL 的文本文件。如果链接在 Excel 中，可以先复制到 `.txt` 文件中，确保每行一个链接即可。
